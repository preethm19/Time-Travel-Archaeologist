# Time-Travel Archaeologist

A small Unity project built around an AI-guided exploration experience in historical and temple-inspired spaces. The project combines a cinematic first-person feel with conversational NPC interactions, atmospheric environments, and a narrative-driven journey through time.

## Overview

This repository contains the Unity project files for a time-travel archaeology prototype. It includes a stylized medieval setting, temple-like ruins, and interactive character moments designed to feel immersive and story-rich.

## Highlights

- Conversational NPC interaction using the Convai Unity SDK
- Medieval and ancient temple-inspired environments
- Exploration-focused scene progression
- Cinematic, story-driven visual presentation
- Prototype scenes for movement, guide prompts, and environment discovery

## Project Structure

- `Assets/` - Unity project assets and scenes
- `Packages/` - Unity package configuration
- `ProjectSettings/` - Unity editor and project settings
- `clips/` - gameplay and visual reference images

## Getting Started

1. Open the project in Unity.
2. Make sure the required Unity version and package dependencies are installed.
3. Load the main scene and enter Play mode.
4. Explore the environment and interact with the NPC-driven narrative flow.

## Notes

This is a prototype and may require the Convai SDK setup and any associated credentials or configuration before running fully in a fresh environment.
